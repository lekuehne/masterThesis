013-BPN_48h-replenish

Short description

Retry of experiment #008 with proper M9 media. In this experiment 7 different conditions — consisting of all possible combinations of P. putida, B. subtilis and a natural soil inoculum — were (co-)cultured in a well mixed environment (96-well-plate). Every 48 h the cultures were diluted 1:5 into fresh M9 media and further used as the new main culture. 12 biological replicates. After the fourth cycle cross contamination was observed.

Data import and processing

Load dependencies.

Process function for excel raw data from Tecan Spark plate reader (Toxic Lab):

process_plate <- function(file_path) {
  raw <- read_excel(file_path, col_names = FALSE)
  
  # Extract plate sections
  OD600  <- raw[37:44, 2:13]
  GFP70 <- raw[70:77, 2:13]
  RFP85 <- raw[103:110, 2:13]
  RFP90  <- raw[136:143, 2:13]
  
  # Convert to long format
  to_long <- function(df, name) {
    out <- as.data.frame(as.table(as.matrix(df)))
    out$wavelength <- name
    return(out)
  }
  
  OD600  <- to_long(OD600,  "OD600")
  GFP70 <- to_long(GFP70, "GFP70")
  RFP85 <- to_long(RFP85, "RFP85")
  RFP90  <- to_long(RFP90,  "RFP90")
  
  # Combine
  plate_concat <- rbind(OD600, GFP70, RFP85, RFP90)
  plate_concat <- setNames(
    plate_concat,
    c("row", "col", "value", "wavelength")
    )
  
  plate_concat$value <- as.numeric(as.character(plate_concat$value))
  plate_concat$well <- paste0(plate_concat$row, plate_concat$col)
  
  # Date + time from same file
  date <- read_excel(file_path, range = "E6", col_names = FALSE)[[1]]
  time <- read_excel(file_path, range = "E7", col_names = FALSE)[[1]]
  
  plate_concat$datetime <- as.POSIXct(paste(date, time))
  
  # Conditions
  plate_concat$condition <- dplyr::recode(
    plate_concat$row,
    "A" = "B",
    "B" = "B+N",
    "C" = "N",
    "D" = "B+P+N",
    "E" = "B+P",
    "F" = "P+N",
    "G" = "P",
    "H" = "M9"
  )
  
  # Final tidy
  plate_concat <- plate_concat[, c("well", "datetime", "condition", "wavelength", "value")]
  
  return(plate_concat)
}
